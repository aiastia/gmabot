# ⚔ 2D 网格生存战

纯 Web 实现的 AI 对战生存游戏，8 位 AI 战士在随机地图上争夺资源、互相战斗，最后存活者获胜。

## 🎮 游戏特色

- **纯本地运行** - 零 API 成本，无需后端
- **状态机 AI** - 每个角色有独立性格（勇猛/谨慎/平衡/贪婪）
- **权重决策** - AI 根据HP、武器、距离等因素智能行动
- **实时观战** - 可调速、暂停、重开

## 🚀 运行方式

### 方式 1：直接打开
```bash
open index.html
```

### 方式 2：本地服务器
```bash
npx serve .
# 或
python3 -m http.server 8080
```

### 方式 3：Docker
```bash
docker compose up
# 打开 http://localhost:8080
```

## 🎯 操作说明

| 按键 | 功能 |
|------|------|
| `空格` | 暂停 / 继续 |
| `R` | 重新开始 |
| `1` | 极慢 (500ms) |
| `2` | 正常 (300ms) |
| `3` | 较快 (150ms) |
| `4` | 极快 (80ms) |
| `5` | 闪电 (40ms) |

## 🗺️ 游戏规则

- **地图**: 40×30 网格，随机墙壁和物品
- **食物**: 拾取恢复 HP +25，补充饱食度
- **武器**: 木棍(+5) < 铁剑(+12) < 神剑(+25)
- **饱食度**: 每回合消耗，归零开始掉血
- **胜利**: 最后存活的 AI 获胜

## 🏗️ 技术架构

```
├── index.html        # 主页面
├── css/style.css     # 样式
├── js/
│   ├── config.js     # 配置常量
│   ├── grid.js       # 地图系统 (BFS 寻路)
│   ├── item.js       # 物品系统
│   ├── entity.js     # 角色实体
│   ├── ai.js         # AI 决策 (状态机 + 权重)
│   ├── combat.js     # 战斗系统 (同时结算)
│   ├── renderer.js   # Canvas 渲染
│   └── main.js       # 游戏主循环
├── Dockerfile        # Docker 部署
└── docker-compose.yml
```
